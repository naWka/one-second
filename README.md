# Одна секунда платежа

Интерактивная история о том, что происходит за ~1 секунду между касанием картой терминала и надписью «Одобрено». Скролл «прокручивает» время: одна реальная секунда растянута на весь сайт, в тысячу раз медленнее.

**Сайт:** https://nawka.github.io/one-second/

Vite + TypeScript, Three.js + [postprocessing](https://github.com/pmndrs/postprocessing) (bloom, зерно, виньетка), GSAP + ScrollTrigger, Lenis. Без React. Вся графика процедурная; единственные внешние данные — контуры суши Natural Earth 110m (public domain).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # статическая сборка в dist/
npm run preview    # посмотреть сборку локально
```

Нужен Node 20+.

Полезные параметры адреса:

- `?debug` — счётчик fps и текущий DPR в правом нижнем углу;
- `?reduced` — режим `prefers-reduced-motion` (статичные кадры с кроссфейдами);
- `?q=low` — принудительно «мобильное» качество.

## Деплой

Сборка статическая (`dist/`), пути относительные (`base: './'`), поэтому работает из любого подкаталога.

- **GitHub Pages** — уже настроено: `.github/workflows/pages.yml` собирает и публикует сайт при каждом пуше в `main` (Settings → Pages → Source: GitHub Actions).
- **Vercel** — импортировать репозиторий, Framework preset: Vite. Build command `npm run build`, output `dist`.
- **Cloudflare Pages** — Build command `npm run build`, output directory `dist`.

## Где что править

| Что | Где |
|---|---|
| Весь текст сайта | `src/content/ru.ts` (для другого языка — скопировать в `en.ts` и переключить импорт в `src/content/index.ts`) |
| Список источников в подвале | `src/content/sources.ts` (зеркало `FACTS.md`) |
| Ставки калькулятора | `src/data/fees.ts` — у каждой цифры комментарий со ссылкой |
| Тайминги HUD-таймера | `src/data/timeline.ts` |
| Сцены (камера, пакет, подписи) | `src/scenes/s0-cover.ts` … `s8-fees.ts` — одна сцена, один модуль |
| 3D-миры (геометрия, шейдеры) | `src/gl/worlds/*.ts` |
| Пакет данных | `src/gl/packet.ts` |
| Звук (Web Audio, без файлов) | `src/core/audio.ts` |
| Стили, палитра, шрифты | `src/styles/main.css`, `src/gl/palette.ts` |
| Точки суши для глобуса | `npm run globe` → `public/land.bin` |

Длина каждой сцены задаётся в экранах (`screens` в `ru.ts`), положение карточек текста внутри сцены — полем `at` (0…1). Текст рендерится в HTML на этапе сборки, поэтому он доступен поисковикам и скринридерам и читается даже без WebGL.

## Документы

- `FACTS.md` — каждое число на сайте: значение, источник, дата, уверенность.
- `STORYBOARD.md` — финальный текст сцен и таблица таймингов HUD.
- `DECISIONS.md` — решения, принятые по ходу, одной строкой каждое.
- `screenshots/` — финальные кадры всех сцен, десктоп 1440×900 и телефон 390×844.

## Скриншоты

```bash
npm run dev -- --port 5179
node scripts/screenshots.mjs http://localhost:5179/ screenshots
```

Скрипт открывает страницу в Playwright, прокручивает к трём точкам каждой сцены и снимает десктоп и телефон.

## Доступность и производительность

- Клавиатура: ↑/↓ — к следующей/предыдущей карточке текста, PageUp/PageDown — между сценами, Tab — по навигации, переключателю звука, «А что, если…» и калькулятору.
- `prefers-reduced-motion`: без пролётов камеры и плавного скролла, статичные кадры сменяются кроссфейдом, весь текст доступен.
- Звук выключен по умолчанию и синтезируется Web Audio только после нажатия кнопки.
- DPR ограничен 1,75 (на телефоне 1,5) и автоматически снижается, если кадры становятся медленными. Миры создаются лениво и прогреваются в простое.
